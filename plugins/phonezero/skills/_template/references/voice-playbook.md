# Voice playbook (chat agent)

Keep the uploaded JSON fields short.

- **goal:** One sentence.
- **opener:** The ask after “calling on a recorded line.” No extra reservation language unless this skill is a reservation.
- **constraints:** What the agent may accept without calling the user back.
- **success:** What a live person must confirm on the read-back.
- **voicemail:** One message. Include spoken name and callback if you do not rely on the interpreter to add them.
- **playbook:** Ordered steps. A few clauses, not a novel.
